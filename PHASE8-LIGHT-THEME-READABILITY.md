# Phase 8 — Light Theme and About Hero Refinement

This release responds to the visual review of Phase 7.

- The main-page and gallery light theme now uses a lighter translucent wash rather than a near-opaque cream overlay, preserving visibility of the underlying background photographs.
- Selected mode, crop, screenshot and Contact panels use less opaque backgrounds; unnecessary blur is removed or minimized.
- The About-page heading emphasis uses a gold/ivory/light-green gradient to remain legible on the dark video.
- The English, Arabic, Spanish and Italian closing-story text no longer says that the platform must be validated and no longer uses the requested final word meaning “responsibly”; the intent to develop and commercialize it remains.
- CSS/JS references use `?v=9` to avoid stale browser cache after deployment.

The package remains a static Cloudflare Pages site. It has not been deployed as part of this release.
